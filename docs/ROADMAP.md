# teamctx 开发路线图

## 🏗️ 架构变更说明

**v0.2.0 引入重大架构调整**：从单团队模式升级为 Discord 风格的多团队去中心化模式：

- ✅ 每个团队自托管独立服务器（去中心化）
- ✅ 桌面客户端支持同时连接多个团队
- ✅ Discord 风格的团队侧边栏
- ✅ 跨团队聚合通知（带筛选）
- ✅ MCP 服务器多团队感知（team 参数）
- ✅ teamctx:// 深链接和邀请系统
- ✅ 客户端数据按团队隔离存储

## 🐛 已知问题

### 高优先级
- [ ] **邀请系统未完整实现** - 后端 API 和深链接处理未完成
- [ ] **Token 未使用安全存储** - 当前存储在 localStorage，应迁移到 keychain
- [ ] Git 监控功能未实现 (只有 API)
- [ ] 桌面应用的文档/需求/问题只读，不能新增/编辑
- [ ] 没有团队/组织管理界面，只能通过 API 操作
- [ ] MCP 服务器文档搜索是客户端实现，应改为服务端
- [ ] 多 WebSocket 断线重连策略需要优化

### 中优先级
- [ ] **团队切换时的数据加载状态** - 需要更好的反馈
- [ ] **跨团队通知过多时的性能** - 需要虚拟滚动优化
- [ ] 没有输入验证和错误提示优化
- [ ] 桌面应用的浮动窗口不可拖动
- [ ] 缺少加载状态和骨架屏
- [ ] 数据库连接池配置需要优化
- [ ] Tauri 图标缺失 (使用占位符)

### 低优先级
- [ ] 单元测试覆盖率不足
- [ ] 缺少 E2E 测试
- [ ] API 文档不完整
- [ ] 日志系统不完善
- [ ] 性能监控缺失

## 🎯 长期愿景

1. **去中心化协作网络** - 团队间可选择性互联，形成协作网络
2. **成为 AI 协作的标准工具** - 被各大 AI IDE 和 Agent 平台集成
3. **知识图谱** - 自动构建团队知识网络，智能推荐相关内容
4. **AI Agent 协作** - 支持多个 AI Agent 跨团队同时工作，自动协调冲突
5. **端到端加密** - 敏感数据端到端加密，服务器不可见
6. **联邦学习** - 在保护隐私的前提下，团队间共享 AI 训练成果
7. **插件生态** - 开放 API，支持第三方扩展
8. **区块链集成** - 可选的工作量证明和贡献追踪

## 📊 版本规划
